# МойЩит — Расширение для браузера

Расширение для Яндекс Браузера (и любого Chromium-браузера) с комплексной защитой и трекером привычек.

## Возможности

| Функция | Описание |
|---|---|
| 🔞 Блокировка порнографии | 70+ сайтов в базе + эвристика по URL |
| 🎰 Блокировка азартных игр | 45+ российских и зарубежных сайтов |
| 🕵️ Блокировка инкогнито | Автоматически закрывает вкладки инкогнито |
| 💧 Напоминания о воде | Каждые 20 минут (настраивается) |
| 🧘 Напоминания об отдыхе | Каждые 50 минут (настраивается) |
| 📚 Трекер привычек | Чтение, медитация, отжимания, пресс + стрики |
| 💰 Накопления | Цель и прогресс накоплений |
| 🔐 PIN-защита настроек | Настройки защищены паролем (SHA-256) |

## Установка

### Шаг 1 — Сгенерировать иконки (уже сделано)
```bash
cd extension/icons
node generate-icons.js
```

### Шаг 2 — Загрузить в Яндекс Браузер
1. Откройте `browser://extensions/` (или `chrome://extensions/`)
2. Включите **Режим разработчика** (переключатель вверху справа)
3. Нажмите **«Загрузить распакованное расширение»**
4. Выберите папку `extension/`
5. Расширение установлено ✅

### Шаг 3 — Установить PIN
При первом открытии настроек (иконка ⚙️ в попапе) вас попросят установить PIN-код.

> ⚠️ **Запомните PIN!** Восстановления нет — это сделано намеренно.

## Защита от удаления (Windows)

Чтобы расширение **нельзя было удалить** через интерфейс браузера:

1. Узнайте ID расширения в `browser://extensions/`
2. Запустите `policy/install-policy.bat` от имени **Администратора**
3. Введите ID расширения
4. Перезапустите браузер

После этого:
- Расширение будет устанавливаться принудительно
- Кнопка «Удалить» исчезнет из интерфейса
- Режим инкогнито будет отключён на уровне ОС

## О блокировке инкогнито на телефоне

> **Важно:** Яндекс Браузер на Android **не поддерживает расширения** в классическом смысле.

Варианты для телефона:
1. **NextDNS / AdGuard DNS** — настройте в Wi-Fi/мобильных данных → автоматически блокирует сайты на уровне DNS
2. **Яндекс Браузер → Семья** (Безопасный поиск + ограничения контента) — встроенная функция
3. **AdGuard для Android** (приложение) — VPN-фильтр с блокировкой сайтов

## Структура файлов

```
extension/

│   ├── popup.html         # Интерфейс попапа
│   ├── popup.js           # Логика попапа

├── options/
│   ├── options.html       # Страница настроек
│   ├── options.js         # Логика настроек + PIN
│   └── options.css        # Стили настроек
├── rules/
│   ├── adult.json         # 70 правил блокировки (declarativeNetRequest)

    ├── windows-policy.json # Шаблон политики

```

## Технические детали

- **Manifest V3** — современный стандарт расширений Chrome/Яндекс
- **declarativeNetRequest** — блокировка на уровне сети (быстро, не грузит CPU)
- **Content Script** — эвристика по URL для сайтов не в базе
- **chrome.alarms** — напоминания (работают даже без открытых вкладок)
- **SHA-256 PIN** — пароль хранится только как хеш, не восстанавливается
- **incognito: "spanning"** — фоновый скрипт перехватывает и закрывает вкладки инкогнито
